# K의 롱폼 팩토리 — 주제 한 줄이면 유튜브 롱폼 완성

**버튼으로 쓰는 16:9 유튜브 롱폼 생성기.** 주제나 내 대본 → 장면 · 자막 · 목소리 → 8~12분 영상, 썸네일 3장, 유튜브 글(제목 · 설명 · 챕터 · 태그)까지 만들어요. 윈도우 10 · 11 전용.

그림으로 보는 설명서: https://k-longform-factory.vercel.app

설치는 [INSTALL.md](INSTALL.md) — 압축을 `C:\LongsFactory` 에 풀고 **클로드 데스크톱 앱 → `</>` 코드 → 로컬 → 폴더 열기** 로 이 폴더를 열고 `설치해줘` 한마디면 됩니다. 필요한 것: 클로드 유료 요금제(Pro 이상) + 클로드 데스크톱 앱(무료 다운로드). Git 같은 나머지 도구는 클로드가 설치해요.

## 버튼 화면 — 바탕화면 'K의 롱폼 팩토리'

1. **대본** — 💡 주제로 대본 쓰기(AI 가 인터넷에서 자료를 찾아 챕터 있는 대본) 또는 📝 내 대본. 목소리는 내 녹음 올리기 또는 무료 기본 목소리(확인용).
2. **연출** — 문장마다 장면을 붙이고, AI 가 유튜브 제목 3개 · 설명 · 태그 · 썸네일 문구를 써요.
3. **미리보기** — 흐린 화질로 먼저 보고, 장면 모음 · 썸네일 3안을 확인해요.
4. **완성** — 자막 있는 mp4 · 자막 없는 mp4 · 썸네일 3장 · 유튜브 글 · 자막 srt.

대본 쓰는 법: `#` 은 영상 제목, `##` 은 챕터(3개 이상이면 유튜브에 챕터가 나와요), 한 줄에 한 문장. 10분이면 문장 150개쯤.

## 말로 시키기 (더 자세히 연출하고 싶을 때)

클로드 앱 `</>` 코드 → 로컬 → 폴더 열기 → `C:\LongsFactory` 에서:

| 말 | 결과 |
|---|---|
| `롱폼 만들어줘 input/대본.md input/녹음.m4a` | 장면 계획 → 미리보기 → 고화질, 확인은 두 번 |
| `얼굴 영상으로 롱폼 만들어줘 input/대본.md input/얼굴.mp4` | 얼굴과 장면이 번갈아 · 작은 창 |
| `튜토리얼 롱폼 만들어줘 input/대본.md input/녹화.mp4` | 화면 녹화의 중요한 곳을 자동 확대 |
| `포인트 색 초록으로` · `배경음 빼줘` | 색 · 소리 바꾸기 |
| `롱폼 어떻게 시작해?` | 처음 쓰는 사람용 안내 |
